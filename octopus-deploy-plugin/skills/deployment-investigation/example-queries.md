# Example Investigation Queries

## Finding Failed Deployments

### Recent Failures in a Space
"Show me all failed deployments in the last 24 hours for the Production space"

### Project-Specific Failures
"Find all failed deployments for the WebApp project in the last week"

### Environment-Specific Failures
"List failed deployments to the Production environment for all projects"

## Analyzing Specific Deployments

### Get Task Details
"Get the full task details for deployment task ServerTasks-12345"

### Review Error Logs
"Show me the raw logs for the failed deployment task ServerTasks-12345"

### Compare Deployments
"Compare the last successful deployment to the latest failed deployment for the API project"

## Investigating Patterns

### Deployment Success Rate
"What's the deployment success rate for the WebApp project over the last month?"

### Environment Health
"Show me deployment success rates across all environments for the last week"

### Time-Based Patterns
"Are there more deployment failures during specific times or days?"

## Cross-Environment Investigation

### Compare Environments
"Why did the deployment succeed in Development but fail in Production?"

### Environment Configuration
"What are the differences in deployment configuration between Dev and Prod environments?"

### Target Health
"Show me the health status of deployment targets in the Production environment"

## Common Questions

- "What was the last error message from the failed deployment?"
- "Has this deployment ever succeeded before?"
- "What changed between the last successful and failed deployment?"
- "Are other projects having deployment issues in this environment?"
- "Is there a pattern to when deployments fail?"
